# QR Quick Lite

Windows 上的极简二维码识别工具。按一次快捷键框选屏幕区域，识别结果直接复制到剪贴板。

## 功能

- 全局快捷键截图识别，不区分显示器与 DPI 缩放
- 资源管理器右键菜单「二维码识别」，点击直接进入截图模式，不必先打开程序
- 结果可一键复制或打开链接
- 支持 13 种码制
- 常驻托盘，空闲时约 7 MB 工作集

## 支持的码制

| 类别 | 码制 |
|---|---|
| 矩阵码 | QR Code、Aztec、Data Matrix、PDF417 |
| 一维码 | EAN-13、EAN-8、UPC-A、UPC-E、ITF、Code 128、Code 93、Code 39、Codabar |

识别分两段：先只认 QR Code，未命中再扫描全部格式。不支持 DataBar、MaxiCode、Micro QR。

## 分发形式

- **安装版**：向导安装，装到当前用户目录，不需要管理员权限；开始菜单与卸载入口齐全。
- **便携版**：解压即用，配置与日志写在程序目录，删除文件夹不留痕迹。

两者都是自包含程序，目标机不需要安装 .NET 运行时。要求 Windows 10 及以上 64 位系统。

## 隐私

- 识别全部在本机完成，不联网，不上传任何图片或识别内容
- 日志只记录运行状态，不记录识别结果
- 只打开 http / https 链接，其他协议一律拒绝

## 右键菜单

只写当前用户注册表，不需要管理员权限；在设置里取消勾选立即移除。文件、文件夹、文件夹空白处、桌面空白处四个位置均可使用。
